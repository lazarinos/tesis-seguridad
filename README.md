# Tesis de seguridad

Planteamiento de investigacion sobre deteccion de intrusiones de red con aprendizaje automatico y tecnicas de explicabilidad (XAI) para PyMES de Juliaca, Puno.

## Archivos principales

- `planteamiento.qmd`: documento principal del planteamiento del problema.
- `referencias.bib`: referencias bibliograficas usadas por el documento.
- `bibliography/`: notas y fuentes de apoyo.
